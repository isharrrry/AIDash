# MOD-006 知识库索引 · 模块说明

> 本目录只放交底文字，代码不在这里。源码位置见同目录《实现约定》§1。

## 职责

把用户目录里的 Markdown 变成**只读**的检索库：增量索引 + SQLite FTS5 全文搜索。

两条安全底线：

- **只读**：`kb.*` 永远不写用户目录（AGENTS §6）；
- **路径安全**：调用方给的 `path` 必须归一化后仍落在 `kbRoot` 内，否则 `../` 能读到仓外任何文件。


## 已知偏差

| # | 设计怎么说 | 实际怎么做 | 影响 |
|---|---|---|---|
| 1 | §3.6.1 校验 `index.md` 的 `okf_version`，给出 `ok/degraded/unavailable` | 不校验版本；`kbRoot` 存在即视为可用 | 不合规的库照样被索引，坏文档进检索结果 |
| 2 | §3.6.2 只索引 `Wiki/`，`RAW/` 与 `Output/` 不索引 | 递归索引整个 `kbRoot`，只跳过 `.git`/`node_modules`/`dist` 等目录；上限 5,000 个文件、单文件 2 MB | 目录里混放的非知识文档也会进检索，命中质量下降 |
| 3 | §3.6.2 报告字段 `added/updated/skipped/invalid` | 实现为 `scanned/indexed/unchanged/removed/errors` | 多了「删除感知」与逐文件错误；字段名不同，调用方按实现为准 |
