# MOD-002 通道与卡片服务 · 模块说明

> 本目录只放交底文字，代码不在这里。源码位置见同目录《实现约定》§1。

## 职责

管两件事：**通道**（`host/project/topic` 三段式、别名、工作目录、在线判定）与**六类卡片**
（info / handoff / question / suggestion / status / artifact）。

卡片是 AIDash 的主数据：发卡时做类型必填校验、敏感模式拦截、幂等去重；
读卡时按通道/任务/类型/状态过滤，并记录「谁在什么时候读到了哪张卡」。

## 已知偏差

| # | 设计怎么说 | 实际怎么做 | 影响 |
|---|---|---|---|
| 1 | 未规定 `status` 卡传了不属于它的字段怎么办 | **已修（决策 A）**：schema 与服务层都明确拒绝 `status`/`handoff` 带 `body_md`，报错提示改用 `detail_md`/`message_md` | 过去实测踩过两次「以为写进去了，实际返回 `body_md: null`」；现在错在入口，不会再有静默丢弃 |
| 2 | §3.2.2 只写幂等键去重 | 额外拒绝跨通道挂任务（`TASK_CHANNEL_MISMATCH`） | 防止任务信息流串通道，属收紧而非放宽 |
| 3 | §3.2 未提「未归属卡」 | 非 question 卡必须带 `task_id`（AGENTS 4.0），历史卡进「未归属消息」折叠区 | 决策台因此只留 question 队列 |
