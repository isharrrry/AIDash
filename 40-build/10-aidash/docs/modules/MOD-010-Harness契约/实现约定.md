## 2 线程与并发

契约本身无运行时。与它相关的运行时约束：

- 工具调用在服务端是普通请求处理，工具之间不共享可变全局状态（除决策等待表）；
- 长等待类工具（`card.wait`）有 25 秒上限，到点返回 `pending`，由 agent 自己续；
- 同一任务只允许一个 `claim_token` 有效，换人必须先 release。

## 3 错误分支

| 触发 | 契约要求 |
|---|---|
| 未认领就调 `task.update(event="start")` | 拒绝，要求先 `task.claim` |
| 未发证据卡就 `complete` | 拒绝，要求先发关联该任务的 status 卡 |
| 已认领但做不完 | 用 `block`，`reason` 必填；不得静默放弃 |
| 没认领且不做 | 用 `defer`，`reason` 必填 |
| 收到 `401` | 立即停止，**不重试**（重试只会把错误令牌刷进日志） |
