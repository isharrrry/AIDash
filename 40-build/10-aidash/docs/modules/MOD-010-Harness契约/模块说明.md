# MOD-010 Harness 契约 · 模块说明

> 本目录只放交底文字，代码不在这里。源码位置见同目录《实现约定》§1。

## 职责

定义「agent 与 AIDash 之间怎么说」，不产生运行时行为：

- MCP 工具清单、入参/出参字段、状态机与流转条件；
- 证据要求（`complete` 前必须先发关联该任务的 status 卡）、阻塞与延后的用法；
- 错误码与 HTTP/RPC 映射；
- 令牌、密钥、脱敏等安全红线。

**两处真源**：`AGENTS.md`（契约主体）与 `skills/aidash-mcp/SKILL.md`（agent 操作手册）。面向人的文档（原仓库根 `docs/`，已于 2026-10-25 合并删除）只给人看，**不得**写 agent 行为规则。
