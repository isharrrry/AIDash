# MOD-008 Web UI · 实现约定

> 本文件只写「怎么落地」。与设计冲突时以设计为准，冲突记在《模块说明》的「已知偏差」。

## 1 单元划分

| 文件 | 职责 |
|---|---|
| `src/web/src/App.tsx` | 路由分发 + 全局上下文 + 401 回登录页 |
| `src/web/src/lib/router.ts` | hash 解析、`navigate`、`channelPath` |
| `src/web/src/pages/*.tsx` | 6 个页面：Home / Tasks / Memory / Reports / Settings / Channel |
| `src/web/src/components/TaskBoard.tsx`、`TaskTree.tsx` | 看板与树、拖拽移动、筛选、搜索 |
| `src/web/src/components/CardDrawer.tsx`、`CardBody.tsx`、`Markdown.tsx`、`MermaidDiagram.tsx` | 卡片详情、Markdown 与 Mermaid 渲染 |
| `src/web/src/components/TopBar.tsx`、`TokenGate.tsx` | 导航与未登录拦截 |
| `src/web/src/api/client.ts` | 统一 REST 客户端：令牌、包络兼容、`ApiError` |
| `src/web/src/api/endpoints.ts` | 每个接口一个函数，类型集中在这里 |

## 2 线程与并发

- 单线程 React；切页/改筛选时用旧请求的 `signal` 取消，避免后到覆盖先到；
- 未读判定用 `IntersectionObserver`（卡片可见 60% 视为已读），**不是**虚拟滚动；
- 任务树是「一次拉取 + 本地不可变过滤」：过滤/搜索都在 `TaskBoard` 内用返回新对象的方式算，不改缓存。

## 3 错误分支

| 触发 | 出口 |
|---|---|
| 401 | `onUnauthorized` 清掉 `localStorage` 令牌并回到 `TokenGate`，不发第二次请求 |
| 4xx/5xx | 抛 `ApiError`（带 `code/status/retryable`），页面弹 Toast 并保留原内容 |
| 网络中断 | 同样落到 `ApiError`，不出现「请求失败但页面照跑」的静默失败 |
| 路由不认 | `notfound` 页，给「返回决策台」 |
| localStorage 不可用（隐私模式） | 按未登录处理，不中断渲染 |

## 5 边界

不在本模块做的事：不在前端计算权限或可推进性、不持有服务端密钥、不做离线缓存。
