# MOD-008 Web UI · 模块说明

> 本目录只放交底文字，代码不在这里。源码位置见同目录《实现约定》§1。

## 职责

浏览器端唯一入口：看卡片、回决策、拖任务树、看汇报与记忆、改设置。

三条边界：

- **只走 REST**：`/api/*` 与 `/healthz`，不直连 SQLite、不读密钥文件；
- **不做业务判定**：排序、可推进性、权限一律以服务端返回为准，前端不自己算一套；
- **令牌在浏览器里**：`localStorage['aidash.token']` → `Authorization` 头；不进 URL、不进日志。
