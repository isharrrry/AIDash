# MOD-009 值守壳 CLI · 实现约定

> **已弃用（2026-10-25）**：本模块在 `src/cli/` 下的实现保留仅为兼容，**新功能只进 `40-build/20-aidash-runner/`**（包名 `aidash-runner`，bin 别名 `aidash-watch`）。本文件描述的是旧实现，语义已与新包不同（命令面、配置 schema、失败策略都不一样），排查问题时先确认跑的是哪一个。
>
> 本文件只写「怎么落地」。与设计冲突时以设计为准，冲突记在《模块说明》的「已知偏差」。

## 1 单元划分

| 文件 | 职责 |
|---|---|
| `src/cli/index.ts` | 入口：帮助、环境检查、启动主循环 |
| `src/cli/config-load.ts` | `aidash-watch.json` 解析与校验（未知键、匹配条件、`gap_seconds`） |
| `src/cli/config.ts` | 运行时配置与 `AIDASH_TOKEN` 校验（缺失/超长/含空白即拒） |
| `src/cli/match.ts` | 任务与 `commands[]` 规则的匹配 |
| `src/cli/mcp-client.ts`、`mcp-parse.ts` | `tools/call` 调用与响应解析 |
| `src/cli/runner.ts`、`exec.ts` | 任务循环、子进程启动、进程树终止 |
| `src/cli/heartbeat.ts` | 心跳与续租；401 后置位「禁止后续调用」 |
| `src/cli/log.ts`、`report.ts` | 脱敏日志与回报内容 |

## 2 线程与并发

- 主循环串行：心跳 → 拉 `pending` → 按 `concurrency` 认领 → 执行 → `gap_seconds` 等待；
- 子进程 stdout/stderr 边读边脱敏，不整段缓存后再打；
- `401` 一到，`heartbeat.ts` 置位并**禁止任何后续 MCP 调用**（包括「尽力释放」），直接退出。

## 3 错误分支

| 触发 | 出口 |
|---|---|
| 缺 `AIDASH_TOKEN` / 含空白 / 超 4096 | `ConfigError`，只报原因不打印值 |
| `aidash_url` 内嵌账号密码 | 拒绝启动 |
| 规则没写匹配条件也没 `match_all` | 配置校验失败（防止「少写一个字段就跑全库任务」） |
| 未知配置键 | 校验失败，列出来 |
| 旧键 `harness`/`tags`/`token_env` | 只告警、不生效，进程继续 |
| 认领失败（被别人抢先） | 跳过这条，继续下一条 |
| 子进程超时 | 终止整棵进程树；`kill` 也没触发 `close` 时强行结束等待 |
