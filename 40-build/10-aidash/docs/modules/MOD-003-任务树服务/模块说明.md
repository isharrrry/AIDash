# MOD-003 任务树服务 · 模块说明

> 本目录只放交底文字，代码不在这里。源码位置见同目录《实现约定》§1。

## 职责

任务树是 AIDash 的「活单」：**建、排、认、做、证**五步都在这里闭环。

- 树结构用**物化路径**（`/tk_root/tk_a/`），子树查询与移动都是前缀改写；
- 状态机 SM-001 **八个**状态（`draft/pending/claimed/in_progress/blocked/done/failed/cancelled`），所有转移先校验后写库；
- 认领是原子的，带租约；租约过期可被任何 harness 接管；
- 完成前必须有证据卡，否则 `EVIDENCE_REQUIRED`。
