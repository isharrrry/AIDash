## 2 E2E（`50-verify/e2e/`）

一条命令：`pnpm -C 40-build e2e`。跑在临时库 + 临时浏览器 profile 上，不碰真实数据。

| 场景 | 说明 |
|---|---|
| 决策台 | 首页加载、卡片可见 |
| 通道页 | 从决策台进入通道、卡片与任务树同屏 |
| 任务树 | 展开/折叠、搜索关键字 |
| 设置页 | 设置项可见、KB 与 LLM 区块 |
| 卡片抽屉 | 打开详情、正文渲染 |
| 鉴权负向 | 错误令牌被挡 |

## 3 手工脚本（`40-build/10-aidash/tests/manual/`）

浏览器端手工回归，按需执行，不进入 CI：`ui-smoke.mjs`、`ui-alias-memory.mjs`、`ui-presence-defer.mjs`、`ui-settings-kb.mjs`、`ui-task-board-batch1.mjs`。

## 4 没覆盖的（明确写出来）

- 移动端与多浏览器兼容；
- 像素级视觉回归；
- 并发与压测（多 harness 同时抢同一任务只做了单测级模拟）；
- 跨主机部署与 TLS；
- MOD-011 的「不得出现旧网关痕迹」扫描（当前无自动化守卫）。
